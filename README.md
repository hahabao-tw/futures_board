# 期貨商公告看板

把臺灣期貨交易所與 13 家期貨商官網的公告區抓下來，彙整成一頁。
GitHub Actions 定時抓取，GitHub Pages 靜態託管。

**收錄範圍：2025-01-01 起的公告，目前約 3,470 則。**

## 臺灣期貨交易所

三個區塊各自獨立呈現在看板第一排，版型相同（`table.table_c`，一列一則，單頁列完）：

| 區塊 | 網址 |
| --- | --- |
| 公告 | https://www.taifex.com.tw/cht/11/announcement |
| 新聞稿 | https://www.taifex.com.tw/cht/11/pressRelease |
| 股票期貨/選擇權契約調整 | https://www.taifex.com.tw/cht/11/adjustContract |

### 幾個踩過的坑

- **台新**：API 名稱和前台路由不一致（`news-domestic-trade` 的 API 叫 `news-dom`）。`linktype` 決定連結型態：0 內文頁、1 附件頁、2 外部連結。
- **富邦／元大**：前台看起來要翻幾十頁，其實 API 一次就回全部。元大的端點少了 `X-Requested-With: XMLHttpRequest` 會回 HTML 首頁。
- **凱基**：頁碼超過最後一頁不會回空，而是繞回第 1 頁，得靠去重收尾。
- **國票**：`xy=1` 和 `xy=2` 內容大量重疊，靠去重收斂；`default2.aspx?xy=5` 是交易所官網連結目錄，不是公告，不收。
- **大昌**：公告有三種版型（連結標題／純文字標題／整則塞在 `<p>`），只抓 `h3 a` 會漏掉一半。
- **期交所轉發的公告**標題含相容表意字（「金」是 U+F90A），看起來一樣但字串比對全失敗，全站統一做 NFKC 正規化。

## 功能

- **看板**：第一排是期交所三個區塊（置中），第二排起是期貨商；
  一個來源一張卡片，預設顯示 40 則，可展開全部
- **時間軸**：16 個來源合併依日期排序，每次載入 300 則
- **搜尋**：跨全站比對標題，命中處標色
- **分類篩選**：保證金／假期／系統／商品／防詐／活動／其他
- **保證金預設收合**：保證金公告佔總量逾半，預設不顯示，可用開關打開；
  主動點選「保證金」分類仍可單獨檢視。開關狀態記在 localStorage
- **字級調整**：六段可選，預設第 2 段（15px），設定記在 localStorage
- **放大鏡**：滑鼠移到公告標題時跟著游標顯示放大鏡片，順便攤開被卡片寬度截斷的標題
- **各家專屬色**：期交所三塊共用金色，13 家期貨商各有色相，
  卡片標題列與時間軸左緣都依來源上色
- 頁面最上方列出不收錄的分類，頁尾顯示資料更新時間、自動更新時刻與管理員信箱
- 停用右鍵選單（純前端嚇阻，開發者工具與檢視原始碼仍繞得過去）

### 視覺

夜間交易台風格，**刻意只做深色一種**、不跟隨系統淺色主題。台股慣例紅漲綠跌，
所以紅色是強調色而非警示色。所有文字對比度實測在 7.4:1 以上（WCAG AA 門檻 4.5:1）。

背景是 `candles.js` 畫的流動 K 線，資料為隨機遊走產生的裝飾，**不代表任何真實行情**。
分頁切到背景時會停掉動畫；`prefers-reduced-motion` 為 reduce 時整個不顯示。

## 本機使用

```bash
npm install
npm run scrape      # 抓取，寫入 site/data.json
npm run serve       # http://localhost:4321
```

只抓特定幾家（除錯時很有用）：

```bash
node scripts/scrape.mjs kgi entrust
```

## 調整收錄範圍

改 `scripts/config.mjs`：

- `SINCE`：起始日期，目前 `2025-01-01`
- `EDGE_KEYWORDS`：不收的邊緣分類關鍵字（樂齡、永續、公平待客、金融友善、徵才、ESG、公益、內控聲明、MultiCharts、顧問講座、熱門、洗錢防制專區）
- `MAX_ITEMS_PER_BROKER`：單一期貨商筆數上限，防爆用

## 部署設定

推上 GitHub 後，到 repo 的 **Settings → Pages**，把 Source 設成 **GitHub Actions**。之後
`.github/workflows/scrape.yml` 會在**台灣時間每天 08:00、11:00、15:00、19:00、23:00**
各抓一次。抓取腳本會比對公告內容指紋，**只有真的出現新公告才會**回寫 `site/data.json`
並重新部署，沒有異動就整個跳過。也可以在 Actions 頁面手動觸發。

> 注意：GitHub Pages 上的內容是公開的。這裡只有各期貨商官網本來就公開的公告標題與連結。

## 專案結構

```
scripts/
  config.mjs          收錄起始日、邊緣分類、筆數上限
  scrape.mjs          抓取流程主控，含失敗時沿用上次資料的邏輯
  serve.mjs           本機預覽用的靜態伺服器
  lib/http.mjs        fetch 包裝：重試、逾時、Big5 解碼、表單 POST、分頁走訪
  lib/util.mjs        日期正規化、分類標籤、NFKC 清理
  sources/taifex.mjs  期交所三個區塊共用的擷取器
  sources/*.mjs       一家一個檔案，index.mjs 是清單、筆劃與排序
site/
  index.html app.js style.css
  candles.js          背景 K 線動畫（純裝飾）
  data.json           抓取結果（由 CI 回寫，約 0.8 MB）
```

## 維護

期貨商改版時，該家會抓到 0 筆而標記失敗，卡片顯示 ⚠ 並沿用上次成功的內容，其餘 12 家不受影響。
修的時候先單獨跑那一家看錯誤訊息，再調整 `scripts/sources/<該家>.mjs`。
